# 客户端与服务端共享契约

`src/` 只包含可序列化展示类型、领域常量和纯函数。网页和桌面使用同一份契约；这里禁止引入 Prisma、Next 服务端 API、文件系统、账号或模型密钥。

- `api.ts`：项目、模型档案、任务与提案展示结构。
- `workspace.ts`：版本号、页面数据、设置和错误结构。
- `desktop.ts`：受控原生桥和设备推理工作项；不包含会话 token。
- `*-view.ts`、`domain.ts`：共享领域展示类型和纯函数。

`web/` 和 `desktop/` 各自独立安装和构建，通过 `@contracts/*` 别名引用源码；服务端的 Docker 和部署源码包同时包含此目录。时间统一使用 ISO 字符串，页面数据不返回服务端存储路径。`/api/v1` 兼容现有业务响应格式，错误至少包含 `{ error: string }`，参数错误返回 422、未登录 401、资源越权 404、过期设备结果 409。
