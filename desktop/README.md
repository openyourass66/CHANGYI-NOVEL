# 长忆原生桌面版 0.2.3

采用 Tauri 2 + React/Vite + Rust + SQLite。运行时不携带 Electron、Node.js、Next.js 服务或 Prisma 引擎；沿用原版页面组件、配色和文档识别逻辑。

## 功能

- 项目库、项目备份恢复与 JSON/TXT 导出。
- TXT、Markdown、DOCX、EPUB、HTML、文本 PDF 导入；章节标题、排序、拆分、合并和删除。
- 故事记忆的分类、搜索、编辑、历史版本、出处定位和冲突审阅；人物认知维护；Markdown/TXT 记忆导入和 Markdown 导出。
- 模型档案的加密保存、默认档案、连接测试；兼容 OpenAI 协议、Anthropic、Ollama 和 LM Studio。云端任务须先预览并授权，本地端点限制为本机或内网地址，连接失败不回退到云端。
- 逐章抽取、全书统合和提案采纳/忽略；模型更新不会覆盖人工修改的记忆。
- 自定义或生成续写方向、手动或模型生成章纲、逐章草稿生成与重新生成、草稿编辑和 TXT 导出。
- 连续性问题、草稿证据定位、问题状态维护、草稿记忆增量提案。草稿正文改变后清理不再对应的检查结果和待审阅提案。
- 模型输出结构校验与一次修复重试；任务进度、取消和中断恢复；恢复只重试失败单元。取消后返回的模型结果不再写入。
- 数据目录切换、复制到空目录、已有工作区打开、启动失败恢复入口；浅色/深色主题、窗口控制和单实例。

## 自动化与作品库

- **全局自动化配置**：在“设置 → 自动化配置”统一保存“自动全部采纳分析记忆”和“分析后自动统合全书”，默认开启，对所有项目的新任务生效。理解分析页面不再展示配置。逐章分析后自动采纳本次任务提案，再进行全书统合并采纳统合结果；人工修改冲突仍需处理，旧的待审阅提案不会被顺带采纳。关闭自动采纳后，流程会在需要审阅时停下，处理后可继续。
- **自动续写**：先配置模型和规划章数，点击“选定此方向并开始续写”。已有章纲直接复用，否则生成章纲；随后按顺序生成缺失正文、检查连续性、提取记忆变化。已有正文保留，草稿记忆作为待审阅提案保存，不直接进入正式故事记忆。方向与事实存在阻断冲突或任务失败时暂停，使用“继续未完成部分”重试；正文生成失败时停止生成后章，已完成章节不重复生成。
- **后台进度**：流程状态和当前子任务写入工作区数据库，切换页面后继续执行；应用关闭期间不运行，重新打开后可继续中断流程。可在全局进度卡停止后续任务。模型服务商、端点、模型或本地属性变更后，必须重新启动并授权流程。运行期间替换原文、修改章节和续写内容及切换工作区受到保护。
- **独立作品库**：自动续写完整流程结束后，将该方向的正文保存为一部独立作品，在主导航“作品库”中以封面卡片展示标题、来源、章节数、字数及生成日期和时间。点击卡片或“开始阅读”进入独立阅读页。完成时保存正文快照；后续修改或删除原项目、方向和草稿，不会改变作品正文。作品支持单独删除及 TXT 导出，删除后不会因历史记录迁移而重新出现。
- **阅读体验**：续写完成后自动保存到作品库，统一从作品库或完成提示进入作品阅读。原项目导航中的“阅读”页面及生成期间的阅读入口已移除，旧阅读地址自动转到作品库。小说阅读器支持目录、上下章、字号、行距、宽度、浅色／深色／护眼背景和全文 TXT 导出，已归档作品按完成时快照阅读。阅读设置、章节及滚动位置保存在当前设备；草稿编辑仍在“续写规划”中进行。
- **提醒规则**：只在整项理解或续写流程完成、方向候选需要选择、流程中断或失败需要处理时播放一次清脆短音，并显示结果入口。单章完成和自动衔接步骤不响铃；切换页面或重启后不重播已通知的结果。声音采用固定规则，不提供声音开关或试听入口。任务启动时直接展示运行状态，不再要求点击启动成功弹窗。

云端分析授权包含随后自动执行的全书统合；自动续写在启动时一次授权章纲、正文、连续性检查和记忆变化提取的数据范围。本地模型不弹云端授权，也不会回退到云端。全局自动化配置、作品及独立章节、流程记录和通知记录保存在原生工作区的附加表中；原有业务表和项目内容保持兼容，项目 JSON 备份仍以小说内容为主。

升级时会自动整理有保留草稿的历史已完成续写流程，使用当前保留正文建立作品快照，并显示原流程完成时间；同一流程只归档一次。旧项目自动化选项迁移为全局配置：任一旧项目关闭过某项时，全局该项先保持关闭，可在设置中统一调整。备份整个作品库和全局配置时，关闭应用后复制整个工作区；单项目 JSON 备份不包含独立作品库。

## 安装与数据

Windows x64 安装包输出到 `src-tauri/target/release/bundle/nsis/`。复用系统 WebView2；缺失时安装程序会联网下载安装，不内置完整浏览器运行时。

0.2.3 安装包为 `长忆原生版_0.2.3_x64-setup.exe`，移除项目阅读页面，续写完成后自动保存到作品库并统一阅读。实测 7,738,515 字节（7.38 MiB）；主程序与安装包版本资源均为 0.2.3，生产构建、原生 release 编译和 NSIS 打包通过，安装包旁提供 `.sha256` 文件。SHA-256：`9E821CCB0CF0A1E3F98E17952CA4F6C915A7B8F1D146B76ED39FCD8649F94ABB`。

0.2.2 安装包为 `长忆原生版_0.2.2_x64-setup.exe`，包含全局自动化配置及独立作品库。实测 7,744,897 字节（7.39 MiB），主程序 12,962,304 字节；主程序与安装包版本资源均为 0.2.2，已完成前端生产构建、原生 release 编译和 NSIS 打包，安装包旁提供同名 `.sha256` 校验文件。SHA-256：`A2FE23E0AD86834DB351A84783B531C845E2EDA6FEC9C0016AD173BA219228D2`。

0.2.1 安装包为 `长忆原生版_0.2.1_x64-setup.exe`，包含自动分析采纳、自动续写、独立阅读器和整项任务提醒改造。实测 7,729,034 字节（7.37 MiB），主程序 12,944,896 字节（12.35 MiB）；主程序与安装包版本资源均为 0.2.1。安装包旁提供同名 `.sha256` 校验文件，旧版安装包保留。

0.2.0 发行包为 `长忆原生版_0.2.0_x64-setup.exe`，实测 7,699,459 字节（7.34 MiB）。主程序 12,870,144 字节（12.27 MiB），另有 160,880 字节的 WebView2 加载库；这些数值不包含系统 WebView2、卸载程序和用户数据。安装包同目录提供 SHA-256 校验文件。

原生版沿用迁移阶段的独立应用标识 `com.changyi.novel.preview`，与原 Electron 版分别保存默认工作区。首次启动可在设置页使用“从已有工作区复制”生成独立副本，原目录保留。切换到空目录会复制当前数据，选择已有工作区会直接打开。更换目录前须先完成或取消任务。

旧工作区需先在原版完成数据库升级。复制包含已提交的 WAL 数据及原文；支持从 `.changyi-storage.json` 或旧 `.env`/`.env.local` 接入加密主密钥，并验证模型密文。密钥缺失或损坏时，可在设置页导入原来的 64 位十六进制主密钥。项目导出不包含模型档案、密文或主密钥。

备份恢复创建新项目，重映射内部引用；失败回滚数据库与新文件。数据目录不可用时保留原路径配置，打开临时恢复工作区并提示重新选择原目录。原生版新建数据暂不承诺由旧版反向打开。

## 开发与打包

需要 Node.js 22.13+、pnpm 11.1.1、Rust 和 Windows 构建工具。由于复用 `../web/src`，迁移分支仍需在 `../web` 安装现有依赖；这些依赖不随原生应用分发。

```powershell
pnpm install
pnpm desktop:dev
```

检查和打包：

```powershell
pnpm test
pnpm test:native
pnpm build
pnpm test:e2e
pnpm desktop:dist
```

`pnpm dev` 用于界面开发；普通浏览器预览不会连接个人工作区或回退到旧服务。构建产物、工具链、个人工作区和密钥均不提交到版本库。
