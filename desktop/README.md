# 长忆原生桌面版迁移

目标架构为 Tauri 2 + React/Vite + Rust + SQLite。运行时不携带 Electron、Node.js、Next.js 服务或 Prisma 引擎；现有页面组件、配色与章节识别逻辑从 `../web/src` 复用。

当前是 **0.2.0-alpha.2 迁移预览版**，尚不能替代功能完整的正式版。

## 已迁移

- 项目库：创建、打开、删除项目。
- 原文导入：TXT、Markdown、DOCX、EPUB、HTML、文本 PDF；在 Worker 中解析，原文保存在本机。
- 章节校对：正文按需读取、标题修改、排序、拆分、合并、删除。
- 备份：兼容 v1/v2 项目 JSON 的恢复、v2 JSON 导出、校对正文 TXT 导出；恢复时重映射章节、记忆、方向与草稿引用。
- 故事记忆：分类与搜索、冲突审阅、创建/修改/删除、历史版本查看与恢复、出处定位；人物认知维护；多文件 Markdown/TXT 记忆导入与 Markdown 导出。导入按分类与键跳过重复条目，单个文件写入失败时回滚该文件。
- 数据隔离：使用 `com.changyi.novel.preview` 独立应用标识；默认工作区位于系统应用数据目录下。
- 工作区复制：从已升级的正式版工作区生成独立副本，使用 SQLite Backup API 包含已提交的 WAL 数据，保留原目录；复制原文及已有 `.changyi-storage.json`，保留模型档案密文。
- 窗口拖动、最小化、最大化、关闭、单实例和浅色/深色主题。

## 开发

安装 Node.js 22.13+、pnpm 11.1.1、Rust stable 和平台构建工具。Windows 正式构建建议使用 Rust MSVC 工具链、Visual Studio C++ Build Tools 与 Windows SDK，并安装 WebView2。完整要求见 [Tauri 文档](https://v2.tauri.app/start/prerequisites/)。

在本目录执行：

```powershell
pnpm install
pnpm desktop:dev
```

由于复用 `../web/src` 中的组件，当前迁移阶段还需先在 `../web` 安装一次现有依赖。`pnpm dev` 仅用于界面预览；浏览器页面不连接本机数据库，也不回退到旧服务。

检查与打包：

```powershell
pnpm build
pnpm test
pnpm test:native
pnpm test:e2e
pnpm desktop:dist
```

正式包在 `src-tauri/target/release/bundle/nsis/`。默认复用系统 WebView2，缺失时联网安装；不在安装包内携带完整 WebView2 运行时。安装包和安装后体积应分别实测，当前功能子集的体积不能代表最终完整功能版本。

浏览器集成测试使用系统 Microsoft Edge，通过测试专用进程连接真实 Rust/SQLite 后端；文档解析运行于实际浏览器 Worker。测试只验证界面到业务后端的链路，不替代打包应用的 IPC、文件对话框及窗口操作验收。

当前预览版通过 7 项文档解析测试、11 项原生数据测试和 3 项浏览器集成测试。x64 NSIS 安装包约 6.44 MiB，不包含系统 WebView2、卸载程序和用户数据，也不代表完整功能最终体积。

## 数据与兼容性

首次启动创建独立空工作区。在设置页使用“从已有工作区复制”导入副本。建议先关闭正式版，保证小说文件与数据库快照一致。原目录含运行中任务时拒绝复制；请先在正式版完成或取消任务。

SQLite 表与当前 Prisma 数据模型兼容，但原生版不会运行 Prisma CLI。现有工作区须先在正式版完成数据库升级；不兼容的旧结构会被拒绝。原生版新建工作区暂不承诺由旧版反向打开。

备份恢复始终创建新项目；失败回滚数据库并清理新文件。项目导出不包含模型档案或密钥。验证只使用合成小说、临时数据库和测试端点，禁止将个人工作区、密钥或原文提交到版本库。
