# 长忆原生桌面版 0.2.0

采用 Tauri 2 + React/Vite + Rust + SQLite。运行时不携带 Electron、Node.js、Next.js 服务或 Prisma 引擎；沿用原版页面组件、配色和文档识别逻辑。

## 功能

- 项目库、项目备份恢复与 JSON/TXT 导出。
- TXT、Markdown、DOCX、EPUB、HTML、文本 PDF 导入；章节标题、排序、拆分、合并和删除。
- 故事记忆的分类、搜索、编辑、历史版本、出处定位和冲突审阅；人物认知维护；Markdown/TXT 记忆导入和 Markdown 导出。
- 模型档案的加密保存、默认档案、连接测试；兼容 OpenAI 协议、Anthropic、Ollama 和 LM Studio。云端任务须先预览并授权，本地端点限制为本机或内网地址，连接失败不回退到云端。
- 逐章抽取、全书统合和提案采纳/忽略；模型更新不会覆盖人工修改的记忆。
- 自定义或生成续写方向、手动或模型生成章纲、逐章草稿生成与重新生成、草稿编辑和 TXT 导出。
- 连续性问题、草稿证据定位、问题状态维护、草稿记忆增量提案。草稿正文改变后清理不再对应的检查结果和待审阅提案。
- 模型输出结构校验与一次修复重试；任务进度、取消和中断恢复；恢复只重试失败单元。取消后返回的模型结果不再写入。
- 数据目录切换、复制到空目录、已有工作区打开、启动失败恢复入口；浅色/深色主题、窗口控制和单实例。

## 安装与数据

Windows x64 安装包输出到 `src-tauri/target/release/bundle/nsis/`。复用系统 WebView2；缺失时安装程序会联网下载安装，不内置完整浏览器运行时。

原生版沿用迁移阶段的独立应用标识 `com.changyi.novel.preview`，与原 Electron 版分别保存默认工作区。首次启动可在设置页使用“从已有工作区复制”生成独立副本，原目录保留。切换到空目录会复制当前数据，选择已有工作区会直接打开。更换目录前须先完成或取消任务。

旧工作区需先在原版完成数据库升级。复制包含已提交的 WAL 数据及原文；支持从 `.changyi-storage.json` 或旧 `.env`/`.env.local` 接入加密主密钥，并验证模型密文。密钥缺失或损坏时，可在设置页导入原来的 64 位十六进制主密钥。项目导出不包含模型档案、密文或主密钥。

备份恢复创建新项目，重映射内部引用；失败回滚数据库与新文件。数据目录不可用时保留原路径配置，打开临时恢复工作区并提示重新选择原目录。原生版新建数据暂不承诺由旧版反向打开。

## 验证

已使用合成小说、临时数据库和本地模拟模型验证文档解析、真实 Rust/SQLite 后端及浏览器界面的完整业务链路。覆盖两种模型协议、结构修复重试、授权拦截、提案版本保护、草稿检查与记忆增量、任务中断恢复、取消后禁止落库、工作区复制和路径配置恢复。

真实服务商的鉴权、模型可用性和限额取决于用户自己的端点与档案，可在设置页执行连接测试。浏览器集成测试不能替代原生文件对话框和不同 Windows 环境的人工验收。

## 开发与打包

需要 Node.js 22.13+、pnpm 11.1.1、Rust 和 Windows 构建工具。由于复用 `../web/src`，迁移分支仍需在 `../web` 安装现有依赖；这些依赖不随原生应用分发。

```powershell
pnpm install
pnpm desktop:dev
```

检查和打包：

```powershell
pnpm test
pnpm test:native
pnpm build
pnpm test:e2e
pnpm desktop:dist
```

`pnpm dev` 用于界面开发；普通浏览器预览不会连接个人工作区或回退到旧服务。构建产物、工具链、个人工作区和密钥均不提交到版本库。
