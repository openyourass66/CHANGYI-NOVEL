# 长忆 · 小说理解与续写工作台

长忆是一款本地小说写作工具，帮助你导入长篇原文、整理人物与故事设定、规划后续情节并生成续写草稿。原文、故事记忆和续写作品分别保存，方便校对、审阅和持续创作。

[下载 Windows 安装包 · v0.2.14](https://github.com/openyourass66/CHANGYI-NOVEL/releases/download/v0.2.14/Changyi_0.2.14_x64.zip) · [版本说明与校验文件](https://github.com/openyourass66/CHANGYI-NOVEL/releases/tag/v0.2.14)

## 功能

- **导入与校对**：支持 TXT、Markdown、DOCX、EPUB、HTML 和文本 PDF，自动识别章节，可修改标题、调整顺序、拆分和合并。
- **故事记忆**：整理人物、设定、时间线、悬念、文风和术语，保留出处及历史版本，保护人工编辑的内容。
- **理解分析**：逐章提取信息并统合全书，可自动采纳分析记忆，也可逐条审阅。
- **续写规划**：填写自己的构思或生成候选方向，智能推荐章数，也可手动指定；章纲与正文均可编辑。
- **自动续写**：按顺序生成正文、检查连续性、提取记忆变化；显示整体进度，支持停止和继续未完成部分。
- **连贯性检查**：检索当前情节相关的故事记忆，核对同方向的续写章节，并显示问题对应的正文证据。
- **作品库与阅读**：完成的续写独立保存，支持目录、阅读样式、进度记忆和全文导出；确认后可将作品正文与记忆并入原作。
- **Token 用量**：顶部查看任务、当前项目和全部项目累计，区分输入与输出并支持模型筛选。用量随模型响应更新，计入已返回用量的失败和重试请求；未提供用量会明确标记，删除项目后保留全部累计。
- **任务提醒**：完成提醒显示 8 秒后自动收起，重启不重复出现；历史结果可从项目或作品库查看。
- **版本更新**：启动后自动检查新版本，也可在设置中手动检查；支持签名校验、下载进度和稍后安装，后台任务未结束时阻止安装。
- **模型配置**：支持 Anthropic、OpenAI-compatible、Ollama 和 LM Studio。云端任务在发送内容前请求授权，本地端点失败不会自动转用云端。

## 安装与开始使用

1. 下载并解压 Windows x64 安装包，以管理员权限运行解压后的安装程序并确认 UAC 提示。应用使用系统 WebView2，缺失时安装程序会提示下载。0.2.13 可在应用内更新，更早版本需先手动安装一次。
2. 打开“设置”，确认数据保存位置并添加模型档案，可先测试连接。
3. 创建项目并导入小说，检查章节识别结果。
4. 在“理解分析”中积累故事记忆，再到“续写规划”确定方向并开始续写。
5. 在“作品库”阅读或导出已完成作品，审阅连续性问题和记忆变化。

没有模型档案时，也可创建项目、导入校对原文和保存自定义续写方向。扫描版 PDF 暂不支持文字识别。生成正文按每章 1,800–3,500 字校验，长度不合格会重试；人工编辑不受此范围限制。自动任务在应用运行期间执行，关闭后可在下次打开时继续未完成部分。

## 数据与备份

数据保存在本机，以“设置 → 数据保存位置”显示的目录为准。切换到空目录会复制现有数据，选择已有工作区会打开其中的内容；原目录会保留。已有用户升级后继续选择原数据目录即可，首次接入其他工作区也可使用“从已有工作区复制”建立独立副本。

- **完整备份**：关闭应用后复制整个数据文件夹，包括隐藏的 `.changyi-storage.json`，保留项目、作品库、模型配置与流程记录。
- **单项目备份**：导出项目 JSON，可恢复为新项目；不包含独立作品库、模型档案、全局设置、自动流程与 Token 用量账本。
- **阅读设置**：阅读位置和样式保存在当前设备中，需要另外保留设备数据。

API 密钥在本机加密保存，不进入项目导出。长忆面向单用户本机使用，不提供账号和云端同步。

## 源码开发

需要 Node.js 22.13+、pnpm 11.1.1、Rust 和 Windows 构建工具。

```powershell
Set-Location desktop
pnpm install --frozen-lockfile
pnpm desktop:dev
```

检查和打包命令均在 `desktop/` 中执行：

```powershell
pnpm test
pnpm test:native
pnpm build
pnpm test:e2e
# 签名打包，更新说明路径按当前版本填写
$env:TAURI_SIGNING_PRIVATE_KEY = "$env:USERPROFILE\.tauri\changyi-updater.key"
pnpm release:build ./release-notes-0.2.14.txt
```

`pnpm dev` 和 `pnpm preview` 用于界面预览，实际业务操作请启动桌面应用。安装包输出到 `desktop/src-tauri/target/release/bundle/nsis/`。测试使用隔离工作区和本地模拟模型；个人数据、密钥及构建产物不提交到 Git。

应用内更新、签名密钥和发布附件说明见 [更新发布指南](desktop/UPDATES.md)。
